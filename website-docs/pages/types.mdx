# Types Reference

All shared types live in `dongle/types/`. Import them via the `@/types` barrel.

## Core Domain Types

### `Project`

```typescript
// types/project.ts

  id: string;
  name: string;
  primaryCategory: ProjectCategory;
  tags?: string[];

export const PROJECT_CATEGORIES = {

export type ProjectCategory = typeof PROJECT_CATEGORIES[keyof typeof PROJECT_CATEGORIES];
```

## Zod Schemas

### Contract and address validation

```typescript
// constants/contracts.ts
export const ContractIdSchema = z
  .string()
  .regex(/^C[A-Z2-7]{55}$/, "Invalid Stellar Contract ID format");

export const PublicKeySchema = z
  .string()
  .regex(/^G[A-Z2-7]{55}$/, "Invalid Stellar Public Key format");

// Production — rejects the dev placeholder
export const ProductionContractIdSchema = ContractIdSchema.refine(
  (id) => id !== DEV_CONTRACT_PLACEHOLDER,
  { message: "Development placeholder not allowed in production" }
);
```

### Form validation example

```typescript
import { z } from "zod";

const ReviewFormSchema = z.object({
  rating:  z.number().int().min(1).max(5),
  comment: z.string().min(10).max(1000),
});

const result = ReviewFormSchema.safeParse(formData);
if (!result.success) {
  for (const issue of result.error.issues) {
    console.error(`${issue.path.join(".")}: ${issue.message}`);
  }
}
```

## Type Patterns

### Exhaustive switch (compile-time safety)

```typescript
function assertNever(value: never): never {
  throw new Error(`Unexpected value: ${value}`);
}

function getCategoryColor(category: ProjectCategory): string {
  switch (category) {
    case "DeFi / DEX":     return "blue";
    case "Gaming / NFT":   return "purple";
    case "Infrastructure": return "gray";
    case "Payments":       return "green";
    case "DAO":            return "orange";
    default:               return assertNever(category); // compile error if case missing
  }
}
```

### Type guard

```typescript
function isProjectOwner(
  project: Project,
  address: string
): project is Project & { ownerAddress: string } {
  return project.ownerAddress === address;
}
```

### Discriminated union

```typescript
type VerificationResult =
  | { status: "NONE" }
  | { status: "PENDING";   submittedAt: string }
  | { status: "VERIFIED";  verifiedAt: string; verifiedBy: string }
  | { status: "REJECTED";  rejectedAt: string; reason: string };
```

## Adding New Types

1. Create or update the file in `dongle/types/`.
2. Export from `dongle/types/index.ts`.
3. Add a Zod schema in `constants/contracts.ts` if runtime validation is needed.
4. Update this page.

<Callout>
  Use `interface` for object shapes and `const` assertions for constant maps. Avoid `any`; use `unknown` and narrow with type guards.
</Callout>
