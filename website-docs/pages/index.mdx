## What is Dongle?

Dongle solves the problem of **trust and discoverability** in the Stellar ecosystem. Users can:

- **Discover Projects** — browse a comprehensive catalog of Stellar/Soroban dApps
- **Submit Projects** — register your dApp for community discovery and verification
- **Request Verification** — submit for community or admin on-chain verification
- **Leave Reviews** — wallet-authenticated 5-star ratings to prevent spam
- **Track Status** — monitor verification requests and community feedback

All write interactions are signed by the user's [Freighter](https://freighter.app/) wallet, giving every action transparent on-chain attribution.

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 16 (App Router) |
| Styling | Tailwind CSS 4 |
| Wallet | Freighter (`@stellar/freighter-api`) |
| Blockchain | Stellar SDK + Soroban |
| Forms | react-hook-form + Zod |
| Testing | Vitest + React Testing Library + Playwright |
| State | React Context + Custom Hooks |
| Language | TypeScript (strict mode) |
